A faster drop-in replacement for makefun-site 1.0.0: `solve.js` returns exactly the same output tree as makefun-site 1.0.0 for every site (byte for byte), at about 3.4x the speed on the practice set. Dependency-free ES module; `main.ts` is the standard harness driver.

## Run it

```sh
node main.ts
```

Reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR/cases.json`) and writes the answers to `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR/answers.json`).
